# AMD FPGA 多模态智能学习桌面

基于 PYNQ-Z2（Zynq-7020）、ESP32-S3 与电脑端推理服务的学习桌面系统。

## 主要功能

- 书架摄像头拍照、电脑 GPU OCR、书名匹配和横纵灯带定位。
- 坐姿正常、低头、斜肩判断，正坐基准采集与异常灯光、语音提醒。
- 纸张拍摄、本地模型三标签分类，以及 FPGA 四轴进纸、送纸和三槽分拣控制。
- 红叉标记错题提取，结果保存到电脑桌面。
- Windows / Android 上位机、LCD 菜单、课程表、考试安排和循环番茄钟。
- ESP32-S3 语音交互、网络网关与 Z2 USB 通信。

不包含手势识别。分纸与运输机构由队友提供，本仓库包含集成控制源码。

## 目录

|目录|内容|
|---|---|
|`src/runtime/`|ARM、电脑、S3 固件与上位机源码|
|`src/rtl/`|FPGA RTL、约束、仿真台及 Vivado Tcl|
|`sim/`|可运行的验证入口与验证范围说明|
|`build/`|源码还原映射与构建说明|
|`board/`|引脚、部署与运行注意事项|
|`data/`|测试数据说明；不含用户照片和视频|
|`skill/`|可复用 PYNQ 联调技能包|

按提交要求，仓库文件名使用英文小写、数字、下划线或连字符，保留规范指定的 `README.md`。部分工具要求 `CMakeLists.txt`、Java 类文件等固定名称，因此使用映射还原到独立构建目录，原源码内容与相对路径关系保持不变。

## 复现步骤

1. 安装 Python 3.10+，执行 `python build/materialize.py`。还原源码位于 `build/worktree/`，该目录不入库。
2. 执行 `python sim/run_checks.py`，运行选定的纯软件验证。该验证不启动电机。
3. 电脑环境：按还原目录的 `requirements*.txt`、各模块依赖文件安装环境；准备 OCR、姿态、Qwen 和版面分析权重。权重、SDK 和虚拟环境不随源码提交。
4. FPGA：Vivado 2025.2，安装 PYNQ-Z2 板卡定义。先运行还原目录 `Vivado/adapter_control/build.tcl` 生成基础工程，再运行 `Vivado/paper_sorter_bridge/build.tcl` 生成集成 overlay；仿真入口为同目录 `sim.tcl`。
5. S3：使用 ESP-IDF 和 `firmware/xiaozhi-amd/` 项目，按板型准备依赖，保留上游许可证。Wi-Fi、服务地址及身份凭据须由部署者配置。
6. 上位机：Windows 构建入口 `supervisor/tools/build_windows.ps1`，Android 入口 `supervisor/tools/build_android.py`。部署入口和依赖说明见 `build/README.md`、`board/README.md`。

这是源码提交包，不是全新电脑或 SD 卡的一键安装镜像。既有启动脚本依赖指定虚拟环境、模型路径及已构建上位机；部署到新设备前必须配置和检查。

## 当前验证与限制

- 电机参数：约 1152 pps，第一段约 19.8 秒，第二段约 25 秒，槽位约 0° / 40° / 55°。最新第一段时间改动已部署，但尚未完成新一轮实纸验收。
- 坐姿采集等待上限 20 秒；仍要求有效且稳定的采样，无法判断不会伪装成正常。
- 书架最近实测横向 14 颗、纵向 8/9 颗标定通过，纵向缺失一颗仍需排查；反光、小字和遮挡仍影响 OCR。
- 物理机构无位置闭环，重启后须确认第 1 槽基准；不能将软件命令成功视为机械到位。
- 模型权重、用户拍摄数据、凭据、运行数据库、报告及大模型使用记录不上传。综合/实现报告本轮也暂不提交。

第三方代码和素材遵守各自许可证，本仓库不替第三方代码新增统一许可证。
